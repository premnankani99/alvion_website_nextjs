# Alvion Technologies - Premium Corporate Portal

An elite, modern, and highly interactive corporate website designed and built for **Alvion Technologies**—a top software development company specializing in enterprise low-code automation (Appian), robust backend architectures (Java), and responsive frontend systems (React/Next.js).

This repository is optimized for speed, responsive design, fluid micro-animations, and visual excellence.

## 🚀 Key Features

*   **Premium Interactive Hero & Home:** Dynamic landing section built with beautiful radial grid overlays, high-fidelity graphics, and modern navigation layout.
*   **Custom About Page:** Complete with Solid Indigo Hero designs, dynamic statistics row, gray-to-color client focus grids, detailed mission-vision pillars, and interactive master technologies grids.
*   **Highly Minimalist Careers Page:** Clean, typography-focused job board displaying detailed specs for 6 primary roles (Appian Developer, React Native Developer, Associate Software Developer, Automation Tester, HR Executive, and Digital Marketing Intern) with zero distractions.
*   **Interactive Contact Us Page:** Styled with light grayish-blue overlays, developers' desk vector graphic, borderless inputs inside a floating white card, and interactive live Google Maps embed of Alvion's Jaipur headquarters.
*   **Parity-Matched Blogs Page:** Clean layout highlighting a single featured item—*"30 Days of System Design"*—with MacBook programming assets and custom fuchsia-pill buttons.
*   **Mobile-Friendly Layouts:** 100% responsive fluid grid scaling across all viewports from 320px mobile up to UltraWide screens.
*   **Smooth Motion Design:** Dynamic hover effects, scale transformations, and stagger transitions powered by Framer Motion.

## 🛠️ Technology Stack

*   **Frontend Framework:** Next.js 15 (App Router)
*   **Library:** React 19
*   **Styling:** Tailwind CSS (fully customized themes & dynamic layouts)
*   **Animations:** Framer Motion (slide-in-up transitions, card hover effects)
*   **Icons:** Lucide React & React Icons
*   **Type Safety:** TypeScript
*   **Compilation Engine:** Next.js Turbopack (fast live reloading)

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/alvion-technologies-next.git
cd alvion-technologies-next
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for production
```bash
npm run build
npm run start
```
